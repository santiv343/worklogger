WORKLOGGER PORTABLE PARA WINDOWS X64

1. Extraé la carpeta completa del ZIP.
2. Ejecutá Worklogger.exe sin moverlo fuera de esa carpeta.

La carpeta assets debe permanecer junto al ejecutable. Worklogger usa Microsoft
Edge WebView2 Runtime, incluido normalmente en Windows 10 y Windows 11. Si no
está disponible, instalalo desde:
https://developer.microsoft.com/microsoft-edge/webview2/

La edición portable no guarda credenciales junto al ejecutable. El API token se
guarda en Windows Credential Manager y la configuración personal en
%APPDATA%\Worklogger.
