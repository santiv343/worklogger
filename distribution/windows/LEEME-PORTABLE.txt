WORKLOGGER PORTABLE FOR WINDOWS X64

1. Extract the entire folder from the ZIP.
2. Run Worklogger.exe without moving it out of that folder.

The assets folder must stay beside the executable. Worklogger uses Microsoft
Edge WebView2 Runtime, normally included with Windows 10 and Windows 11. If it
is unavailable, install it from:
https://developer.microsoft.com/microsoft-edge/webview2/

The portable edition does not store credentials beside the executable. API
tokens are stored in Windows Credential Manager and personal settings in
%APPDATA%\Worklogger.
